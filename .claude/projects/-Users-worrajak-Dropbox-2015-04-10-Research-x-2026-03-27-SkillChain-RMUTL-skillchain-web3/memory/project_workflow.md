## แผนการทำงาน SkillChain RMUTL

### Role ทั้งหมด (ปรับจากเดิม)
- **superadmin** — ผู้ดูแลระบบสูงสุด
- **admin** — แอดมิน
- **teacher** — อาจารย์ที่ปรึกษา
- **project_staff** — คณะทำงานใต้ร่มพระบารมี (ใหม่)
- **rmutl_staff** — คณะทำงาน มทร.ล้านนา (ผู้ว่าจ้างเทียม + ผู้ประเมิน) (ใหม่)
- **employer** — ผู้ว่าจ้างภายนอก
- **student** — นักศึกษา
- **donor** — ผู้บริจาค

### ลำดับการลงทะเบียน + ใครยืนยันใคร
1. อาจารย์/คณะทำงาน → admin ยืนยัน → ให้สิทธิ์ตาม role
2. ผู้ว่าจ้าง → อาจารย์/คณะทำงานใต้ร่ม/admin ยืนยัน
3. นักศึกษา → อาจารย์/คณะทำงาน/admin ยืนยัน credential level
4. ผู้บริจาค → admin/คณะทำงานใต้ร่ม ยืนยัน (เพื่อสิทธิ์ทางกฎหมาย/ภาษี)

### หลักการประเมิน = เฉพาะงาน
- ทุกการประเมินต้องผูกกับ job_id เฉพาะ (เหมือน Grab ให้ดาวเฉพาะเที่ยว)
- ไม่สามารถประเมินแบบกว้างๆ ได้ ต้องเป็นงานที่ตัวเองเกี่ยวข้อง
- rmutl_staff ถือเป็นผู้ว่าจ้างเทียม + ผู้ประเมินทักษะ นศ. ในตัว

**Why:** ป้องกันการประเมินอคติ ทุกคะแนนต้อง trace กลับไปที่งานเฉพาะได้
**How to apply:** ทุก review form ต้อง require job_id + ตรวจสอบว่า reviewer มีส่วนเกี่ยวข้องกับงานนั้นจริง
